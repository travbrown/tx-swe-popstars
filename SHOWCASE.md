A music trivia web game. A song plays via the Spotify API and you identify the correct artist by clicking their floating bubble. Supports single player, multiplayer (turn-based), and challenge modes. Three difficulty levels control the number of decoy bubbles. Firebase-powered global leaderboard. Built during Google's Tech Exchange program with Latifat Ozoya, Lauren Fraser, and Tariq Thomas.
