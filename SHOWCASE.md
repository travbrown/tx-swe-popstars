I built Pop Stars during Google's Tech Exchange program alongside three teammates — a real-time music trivia game that streams songs through the Spotify API and challenges you to tap the correct artist bubble before time runs out. It supports single-player, turn-based multiplayer, and shareable challenge modes, with three difficulty settings that dial up the number of decoy bubbles. A Firebase-backed global leaderboard tracks top scores, and the whole experience runs live in the browser with no install required.
